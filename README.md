# IWAYA — Below the Surface

A standalone, responsive editorial-style website for an investigative project about drainage conditions in Iwaya, Lagos State.

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**, or click **Go Live**.

## Files
- `index.html` — page structure and project content
- `styles.css` — visual design and responsive layouts
- `script.js` — navigation, scroll progress and reveal effects

## Before publication
Replace the clearly marked visual placeholders with original Iwaya field photographs. Add only verified observations, interview quotations, research findings, team details and recommendations. Do not treat the example issue categories as confirmed findings until the fieldwork supports them.

The design uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.
